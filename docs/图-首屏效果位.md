# README 首屏效果位（占位说明）

README 第一屏留了一个图片位，但**现在还没放图** —— 在那之前保持注释状态，不要留半张破图。

## 要拍什么

一张能同时说明"这是什么"和"它在跑"的截图，建议这样：

1. 进一个 1.21.5 – 26.3 的世界（按映射表选对应变体），装上 `doom.schedule/`，`/reload`；
2. 聊天栏依次打（中间隔几秒）：

   ```
   /function doom.schedule:schedule {run:'say 5 秒到了',time:5,unit:'s',id:'demo1'}
   /function doom.schedule:schedule_with_retry {run:'say 重试版',time:3,unit:'s',id:'demo2',retry:2,retry_delay:10}
   /function doom.schedule:cancel_one {id:'demo1'}
   ```

3. 在"任务已经排进去、还没到点"的那一刻按 F2，这样截图里能同时看到聊天栏的回显。

## 拍完怎么放

1. 存成 `docs/assets/首屏效果.png`（建议宽 1280–1600，透明边裁掉）；

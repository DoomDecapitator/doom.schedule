## 二、第三方边界

| 项 | 情况 |
|---|---|
| 游戏本体资源 | 没有包含任何 Mojang 资源。`data/` 里只有 mcfunction 与 JSON 标签，没有贴图、模型、音效 |
| 第三方数据包 | 没有引用、也没有内嵌任何第三方库。不吃 Bookshelf（`bs.*`）、不吃 `gu`、不吃任何 `lib_*` |
| 原版函数 | 只调用原版命令（`data` / `execute` / `scoreboard` / `tellraw` / `return` / `time`），没有覆盖原版函数或标签 |
| 生成器 | 没有。本包是手写 mcfunction，仓库里没有 `src/`，也没有需要跑脚本才能得到的内容（见 [README 的“源码在哪”](../README.md)） |
| mcdoc 定义 | 自行编写，格式遵循公开的 mcdoc 规范（Spyglass / Misode 的编辑器插件），不包含它们的代码 |

## 三、致谢

- Mojang / Microsoft，Minecraft Java 版，以及这一版新增的 `execute ... summon`、
  `return run`、`data modify ... set from`、`storage` 这些让“纯数据包调度器”可行的命令能力。
- Spyglass / Misode，`mcdoc` 这套编辑器补全方案，以及它的公开格式文档。
- bs.schedule / D-Better-Schedule，同生态里先走一步的调度类数据包。本包拿它们的取舍当对照表
  （见 [13-兼容与版本](13-兼容与版本.md)），本包的“离线队列 + 重试 + 暂停”三件套，正是从那些取舍里长出来的。

## 四、反馈

装的时候卡住了、到点没执行、或者发现了本文档没写的坑，去仓库的
[Issues](https://github.com/DoomDecapitator/doom.schedule/issues) 报。表单会问你要
包版本 · Minecraft 版本 · 复现步骤 · 日志这四样，缺了会很难查。

安全问题请走 Issue 里的说明，不要在公开 Issue 里贴服务器地址或玩家 UUID。
